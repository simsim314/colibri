# GPT-OSS `--debug` execution reports

`--debug` enables live structured execution tracing and keeps a per-token/per-layer report in memory until shutdown.

```bash
./c/colibri \
  --gguf MODEL.gguf \
  --device cuda \
  --prompt 'Write three short sentences about Paris.' \
  --max-tokens 40 \
  --debug \
  --debug-dir /tmp/gptoss-debug
```

When `--debug-dir` is omitted, the runtime creates a directory named like:

```text
colibri-debug-20260726-173000-12345
```

Files:

- `run.log`: complete structured trace for startup, prompt, generation, output, save, and cleanup.
- `token-*.log`: one separate log for every token that was actually forwarded through the model.
- `summary.log`: in-memory token/layer/expert statistics written at shutdown.

Every trace line begins with `DBG|`. Important fields include:

- `event=layer_begin` / `event=layer_end`
- `event=router`
- `event=expert_acquire`
- `event=expert_end`
- `event=op` with `class=copy`, `class=run`, `class=free`, or `class=alloc`
- `event=output` with exact generated bytes encoded as hexadecimal

Each layer summary reports selected and executed expert counts, CUDA/CPU execution counts, cache hits/misses/evictions, experts resident in CUDA before and after, and copy/run/free/allocation timing.

Examples:

```bash
# Exact generated output
grep 'event=output' /tmp/gptoss-debug/run.log \
  | sed -n 's/.*|hex=//p' \
  | xxd -r -p

# One generated token, all layers
grep 'token_seq=43|' /tmp/gptoss-debug/run.log

# Layer summaries only
grep 'event=layer_end' /tmp/gptoss-debug/run.log

# All expert routing and placement decisions
grep -E 'event=router|event=expert_acquire|event=expert_end' /tmp/gptoss-debug/run.log

# All copies/uploads
 grep 'event=op' /tmp/gptoss-debug/run.log | grep 'class=copy'

# All compute operations
 grep 'event=op' /tmp/gptoss-debug/run.log | grep 'class=run'

# All releases/frees
 grep 'event=op' /tmp/gptoss-debug/run.log | grep 'class=free'

# Slowest operations
 grep 'event=op' /tmp/gptoss-debug/run.log \
  | awk -F'|' '{ms=-1; for(i=1;i<=NF;i++) if($i ~ /^ms=/){split($i,a,"="); ms=a[2]} if(ms>=0) print ms "\t" $0}' \
  | sort -nr \
  | head -40

# Compact in-memory summaries written at shutdown
grep '^DBG_SUMMARY|event=layer' /tmp/gptoss-debug/summary.log
```

The timings cover each top-level GPT-OSS allocation, host decode/copy, KV copy, CUDA upload, matrix/attention/router/expert computation, cache eviction/release, usage-file save, scratch free, and model cleanup operation. CUDA-library internals remain included in the elapsed time of the enclosing upload or compute call.
